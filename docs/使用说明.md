# 使用说明

业务项目引用 `src/Alita.AdSDK.ByteDance.OceanEngine/Alita.AdSDK.ByteDance.OceanEngine.csproj`。接口客户端在命名空间 `Alita.AdSDK.ByteDance.OceanEngine.Api`，模型在 `Alita.AdSDK.ByteDance.OceanEngine.Api.Models`。

## 注册

```csharp
using Alita.AdSDK.ByteDance.OceanEngine;
using Alita.AdSDK.ByteDance.OceanEngine.Api;
using Alita.AdSDK.ByteDance.OceanEngine.Api.Models;

builder.Services.AddOceanEngineClient(options =>
{
    options.AccessToken = accessToken;
    // 沙箱等环境可以改根地址，默认是 https://api.oceanengine.com
    // options.BaseAddress = new Uri("https://api-sandbox.oceanengine.com");
});
```

令牌会过期时，用工厂每次取最新值。工厂优先于固定的 `AccessToken`。

```csharp
builder.Services.AddOceanEngineClient(options =>
{
    options.AccessTokenFactory = cancellationToken => new ValueTask<string?>(LoadTokenAsync(cancellationToken));
});
```

令牌来源更复杂时，先注册自己的 `IOceanEngineAccessTokenProvider`，再调用 `AddOceanEngineClient`。`GetAccessTokenAsync` 返回空字符串或 `null` 时，这次请求不带 `Access-Token`。换取令牌的接口就利用这一点：当时还没有业务令牌，请求头里不会塞一个空令牌。

## 调用接口

路径和官方 URL 对应。例如获取千川计划列表，对应 `/open_api/v1.0/qianchuan/ad/get/`：

```csharp
var client = provider.GetRequiredService<OceanEngineClient>();
var filtering = new QianchuanAdGetV10Filtering
{
    MarketingGoal = QianchuanAdGetV10FilteringMarketingGoal.VIDEO_PROM_GOODS,
};

var response = await client.Open_api.V10.Qianchuan.Ad.Get.GetAsync(config =>
{
    config.QueryParameters.AdvertiserId = advertiserId;
    config.QueryParameters.Filtering = OceanEngineJson.Serialize(filtering);
    config.QueryParameters.Page = 1;
    config.QueryParameters.PageSize = 20;
});
```

提交 JSON 请求体的接口直接传模型：

```csharp
var token = await client.Open_api.Oauth2.Access_token.PostAsync(new Oauth2AccessTokenRequest
{
    AppId = appId,
    AuthCode = authCode,
    Secret = secret,
});
```

方法和模型上的中文注释来自官方接口说明。`Open_api.Query_models` 不是巨量的真实接口，只是为了把查询对象的模型生成出来，不要调用它。

## 查询参数

数字、布尔、枚举直接赋给查询参数。对象和数组必须先变成一段 JSON 字符串，不能拆成 `filtering.marketing_goal=...`。

| 方法 | 用途 |
| --- | --- |
| `OceanEngineJson.Serialize` | 单个对象，例如 `filtering` |
| `OceanEngineJson.SerializeAll` | 模型数组 |
| `OceanEngineJson.SerializeValues` | `long`、`string` 这类简单类型的数组 |

## 大文件上传

生成的 `MultipartBody` 把文件放在 `byte[]` 里，整个文件会进内存。大文件改用 `OceanEngineUpload.PostAsync`，它从 `Stream` 往外写，内存里只保留发送缓冲。

```csharp
await using var file = File.OpenRead(videoPath);
var json = await OceanEngineUpload.PostAsync(
    httpClientFactory,
    options,
    "/open_api/2/file/video/ad/",
    new Dictionary<string, string>
    {
        ["advertiser_id"] = advertiserId.ToString(),
        ["upload_type"] = "UPLOAD_BY_FILE",
        ["video_signature"] = md5,
    },
    "video_file",
    file,
    "demo.mp4");
```

这不是自动分片。视频、图片这类接口要一次提交整个文件，只是不再把文件复制成字节数组。官方单独规定了分片的接口才分段传，例如千川人群包 `/open_api/v1.0/qianchuan/audience_file/part_upload`。每段用自己的流，字段按该接口文档填写，例如 `part_num`、`file_key`、`is_finished`。不要把整文件读进内存后再切开。

## 错误和重试

返回体是 JSON，且带数字字段 `code` 时，`code` 不为 0 会抛出 `OceanEngineException`：

- `Code`：业务错误码
- `Message`：返回信息
- `RequestId`：请求日志 ID，对应 `request_id`

GET 遇到 `40100`、`40110`、`40130`、`51010` 时会再请求，间隔 1 秒、2 秒，最多 3 次。POST、上传等非 GET 请求失败后不自动重试。

## 更新接口

官方 Go SDK 更新后，用它的目录重新生成 `Api` 项目。手写的令牌、错误和重试代码在 `OceanEngine` 项目里，生成时不会覆盖。

```powershell
./tools/generate.ps1 <ad_open_sdk_go 目录>
```
